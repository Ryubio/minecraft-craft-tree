# Minecraft Crafting Skill Tree (Yetenek Ağacı)

🇬🇧 **English**
An interactive "Skill Tree" mini-game for Minecraft crafting recipes! All items in the game are displayed on a massive, interconnected skill tree.
- You start with only natural (Tier 0) items unlocked.
- Items that can be crafted from your unlocked materials will glow yellow.
- Click on yellow items to "unlock" them, which in turn reveals more advanced items down the tree!
- Features zooming, panning, and a progress tracker. Everything runs locally in a single HTML file with no server backend required.

🇹🇷 **Türkçe**
Minecraft üretim (crafting) tarifleri için hazırlanmış interaktif bir "Yetenek Ağacı" (Skill Tree) mini-oyunu! Oyundaki tüm eşyalar devasa ve birbirine bağlı bir yetenek ağacı üzerinde gösterilir.
- Başlangıçta sadece doğadan toplanabilen temel (Tier 0) eşyalar açıktır.
- Elinizdeki açık malzemelerle üretilebilen yeni eşyalar sarı renkte parlar.
- Sarı eşyalara tıklayarak kilidini açabilir ve ağaçtaki daha gelişmiş eşyaların yolunu açabilirsiniz!
- Yakınlaştırma (zoom), kaydırma ve ilerleme yüzdesi takibi içerir. Her şey tek bir HTML dosyası içinde, hiçbir sunucuya ihtiyaç duymadan çalışır.

## How to use / Nasıl kullanılır?
Just open `index.html` in any modern web browser.
*Sadece `index.html` dosyasını herhangi bir web tarayıcısında açmanız yeterlidir.*
